# URL Shortener

A simple Vercel-ready URL shortener.

## Deploy on Vercel
1. Upload this folder to GitHub.
2. Import the repository in Vercel.
3. Click Deploy.
4. Open your generated `.vercel.app` URL.

## Important
This demo stores URLs in server memory, so saved links are not permanent across server restarts/redeployments. For a production URL shortener, connect a database such as MongoDB.
